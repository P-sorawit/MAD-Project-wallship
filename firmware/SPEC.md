## 3. กติกา

| ข้อ | กติกา | สถานะ |
|---|---|---|
| 3.1 | **เลือกโหมด**: P1 เท่านั้นที่เลือกได้ จอ P2 แสดงรอ | ✅ |
| 3.2 | **วางเรือ**: เลือกความยาวบน TFT ก่อน แล้วกดช่องบน**แผงเรือตัวเอง**ทีละช่อง | ✅ |
| 3.3 | ช่องต้องว่าง, ติดกับช่องก่อนหน้า, อยู่แนวเดียวกับที่ล็อกจากสองช่องแรก (กันรูป L) | ✅ |
| 3.4 | ต่อเรือได้**ทั้งสองปลาย** (proposal เขียนแค่ "ติดกับช่องก่อนหน้า") ❓ | ✅ |
| 3.5 | ยังไม่เลือกความยาวแล้วกดช่อง → เสียง error ไม่บันทึก | ✅ |
| 3.6 | เปลี่ยนความยาวกลางคัน → ทิ้งช่องที่กดค้างของลำนั้น | ✅ |
| 3.7 | วางครบลำแล้ว ถ้ายังเหลือความยาวเดิม จะเลือกค้างไว้ให้ | ✅ |
| 3.8 | CANCEL = ล้าง**ทั้งกระดาน**ของฝั่งนั้น | ✅ |
| 3.9 | CONFIRM กดได้เมื่อครบ 6 ลำ, กดแล้วแก้ไม่ได้, รออีกฝั่ง | ✅ |
| 3.10 | วางเรือสองฝั่ง**พร้อมกัน**ได้: กดสลับกันทีละช่องได้, CANCEL ของฝั่งหนึ่งไม่กระทบอีกฝั่ง, ใครกด CONFIRM ก่อนก็ได้, กดสวิตช์พร้อมกันในรอบสแกนเดียวกันได้ครบทั้งคู่ (มีเทสต์) | ✅ |
| 3.11 | **ยิง**: กดช่องบน**แผงโจมตีตัวเอง** เฉพาะตาตัวเอง (กดผิดตา = ไม่มีอะไรเกิด ไม่มีเสียง) | ✅ |
| 3.12 | ยิงช่องที่เคยยิง → เสียง error ไม่เสียตา | ✅ |
| 3.13 | HIT / SUNK → ยิงต่อ, MISS → สลับตา | ✅ |
| 3.14 | ยอมแพ้: กด**สวิตช์ยอมแพ้**ของฝั่งตัวเอง ได้ใน S3 และ S4 ไม่ต้องรอตาตัวเอง (กดตอนอื่นไม่มีผล) — **จบเกมทันทีใน EXTI ISR** ไม่รอ main loop (ถ้า loop กำลังอยู่ในโค้ดเกม จะทำต่อทันทีที่ออก) | ✅ |
| 3.15 | โหมด 1 คน: AI เป็น P2 วางเรือสุ่มทันทีตอนเข้า S2 | ✅ |
| 3.16 | AI ยิงห่างกันนัดละ **0.9 วินาที** ให้ผู้เล่นดูทัน | ✅ |
| 3.17 | AI ระดับ **BALANCED** (heuristic) — proposal เขียนว่า "สุ่มยิง" ❓ ให้เลือกระดับในเกมไหม | ✅ |

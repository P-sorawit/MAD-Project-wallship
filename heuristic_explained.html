01

Hunt

ตอนยังหาเรือ ให้ช่องที่รองรับรูปแบบเรือได้มากมีคะแนนสูง

02

Target

เมื่อมี HIT ให้เพื่อนบ้านแนวตั้ง/นอนมีโบนัสที่ใหญ่กว่า Hunt ชัดเจน

Resolve

เมื่อ SUNK ใช้พิกัดเรือทั้งหมดจาก event เพื่อแยกเรือที่แตะกัน

2 · ดูอัลกอริทึมทำงานทีละขั้น

ตัวอย่างนี้ใช้ Balanced profile และเรือทุกขนาดยังเหลืออย่างละ 2 ลำ กดแต่ละขั้นหรือกด “เล่นอัตโนมัติ” เพื่อดูว่าข้อมูลชุดเดียวค่อย ๆ กลายเป็นพิกัดยิงอย่างไร

HIT ที่ยังไม่รู้ว่าเป็นเรือลำใด MISS ขวางการวาง SUNK ขวางการวาง

MISS → บันทึก CELL_MISS → จบเทิร์น AI
HIT → บันทึก CELL_HIT → AI ยิงต่อ
SUNK → รอพิกัดทั้งลำ → CELL_SUNK → AI ยิงต่อ
รูปแบบที่ถูกกติกา—
คะแนนสูงสุด—

3 · Hunt mode: นับความเป็นไปได้

สำหรับเรือขนาด 1, 2 และ 3 ที่ยังไม่จม AI ลองเลื่อนเรือแนวนอนและแนวตั้งไปทั่วกระดาน รูปแบบที่ผ่าน UNKNOWN หรือ HIT ใช้ได้ ส่วนรูปแบบที่ชน MISS หรือ SUNK ใช้ไม่ได้

Hunt score += hunt_weight × จำนวนเรือขนาดนั้นที่ยังเหลือ

เรือขนาด 1 ถูกนับเพียงหนึ่ง orientation เพื่อไม่ให้ได้คะแนนซ้ำ ช่อง HIT ช่วยตรวจความเข้ากันได้ แต่ AI ยิงได้เฉพาะช่อง UNKNOWN

ทำไมกลางกระดานมักสูงกว่า?

เรือยาวสามารถคร่อมช่องกลางได้จากหลายตำแหน่ง ขอบและมุมมีรูปแบบผ่านได้น้อยกว่า แต่ MISS/SUNK รอบกลางอาจทำให้คะแนนบริเวณอื่นสูงกว่าแทน

for each remaining ship length:
  for each horizontal/vertical placement:
    if every cell is UNKNOWN or HIT:
      add hunt score to UNKNOWN cells

4 · Target mode: HIT เปลี่ยนลำดับความสำคัญ

H เดียว

? ← H → ?

ให้ adjacent bonus เฉพาะซ้าย ขวา บน ล่าง ที่ร่วมอยู่ในรูปแบบเรือที่เป็นไปได้

H เรียงแนว

? ← H H → ?

ถ้ารูปแบบเรือมี HIT ตั้งแต่ 2 ช่อง จะให้ line bonus กับ UNKNOWN ในแนวเดียวกัน

ช่องว่างระหว่าง HIT

H → ? ← H

ช่องกลางเข้ากับเรือยาว 3 จึงได้ line bonus เช่นกัน

โบนัสใช้ค่าสูงสุด ไม่บวกซ้อน — target level ของแต่ละช่องมีเพียง 0, 1 หรือ 2 เพื่อไม่ให้กลุ่ม HIT จากเรือหลายลำที่แตะกันดันคะแนนสูงผิดปกติ

5 · ทดลอง Score Map ด้วยตัวเอง

คลิกช่องเพื่อวน UNKNOWN → HIT → MISS → SUNK แล้วดูคะแนนใหม่ ตัวอย่างนี้ไม่ใส่ random jitter เพื่อให้เห็นเหตุผลของคะแนนชัดเจน; โค้ด C จริงเพิ่ม jitter ก่อนเลือก

UNKNOWN HIT MISS SUNK คะแนนสูงสุด

ป้าย +ADJ และ +LINE แสดงโบนัสเป้าหมาย ตัวเลขกลางช่องคือคะแนนก่อน jitter

6 · เรือแตะกัน และเหตุผลที่ SUNK ต้องมีพิกัด

H H H H H
└─ AAA ─┘└ BB ┘

HIT ห้าช่องติดกันอาจเป็นเรือยาว 3 แตะกับเรือยาว 2 จึงห้าม flood-fill หรือสรุปจากความติดกันเพียงอย่างเดียว

เมื่อเกิด SUNK ระบบส่ง ship_length และพิกัดทุกช่องของลำนั้นเข้ามา AI ตรวจว่าพิกัดไม่ซ้ำ อยู่ในกระดาน เรียงตรง ต่อเนื่อง เป็น HIT ทั้งหมด และมีพิกัดนัดล่าสุดอยู่ด้วย

เมื่อผ่านจึงเปลี่ยนเฉพาะช่องเหล่านั้นเป็น SUNK และลดตัวนับเรือหนึ่งครั้ง HIT ที่แตะอยู่แต่เป็นอีกลำยังคงเป็น HIT

8 · ไฟล์ไหนใช้จริง?

wallship_ai.hชนิดข้อมูล, state และ public API ของ AICORE
wallship_ai.cวางเรือ, RNG, heuristic scoring, เลือกยิง, รับผลCORE
wallship_play.cเกม terminal สำหรับคนเล่นกับ AI; เรียกใช้ core สองไฟล์ด้านบนDEMO
play_wallship.ps1คำสั่งช่วยคอมไพล์และเปิด demo บน WindowsDEMO
นำ AI ไปใช้ใน STM32
ใช้ wallship_ai.c และ wallship_ai.h แล้วให้ application/main loop ของ STM32 เรียก API และส่งผลยิงกลับเข้ามา หากใช้ตัวอย่าง event/state machine ของโปรเจกต์ ให้เพิ่มไฟล์ใน examples/ หรือเขียน integration ของบอร์ดเอง
ส่งให้คนอื่นเล่น demo จาก source
ต้องส่งอย่างน้อย 4 ไฟล์ด้านบน และเครื่องผู้เล่นต้องมี gcc ใน PATH เพราะ PowerShell script ทำหน้าที่คอมไพล์ก่อนรัน การส่ง play_wallship.ps1 เพียงไฟล์เดียวไม่พอ

คำสั่ง demo

powershell -NoProfile -ExecutionPolicy Bypass -File .\play_wallship.ps1 balanced 123

# เปิดตำแหน่งเรือ AI เพื่อสาธิต seed และการวางเรือ
powershell -NoProfile -ExecutionPolicy Bypass -File .\play_wallship.ps1 aggressive 124 --reveal
